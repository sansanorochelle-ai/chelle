# Teacher Chelle's Classroom Games

Interactive English games for elementary learners. Open the website's home page to choose a game, or run any game's `index.html` locally in a browser.

## Games

| Game | Practice | File |
| --- | --- | --- |
| Fruit Slash | Fruit vocabulary; solo or two teams | [Play file](fruit-slash/index.html) |
| Color Game | Color vocabulary | [Play file](color-game/index.html) |
| Do You Like Food? | Food vocabulary and speaking | [Play file](do-you-like-food/index.html) |

## Use in class

Open the published GitHub Pages site and select a game. The Fruit Slash file also works offline: download `fruit-slash/index.html` and open it in a browser. On an interactive TV, two students can slash in the left and right lanes at the same time. Scores carry over between rounds, and the teacher manually starts the next round after changing players.
